# Kingsman Barbershop — Премиальная система онлайн-записи

Полнофункциональное веб-приложение для барбершопа, разработанное на чистом PHP (MVC-архитектура без тяжелых фреймворков) с использованием PDO, Bootstrap 5 и MySQL. Проект включает в себя интерактивную онлайн-запись, личный кабинет клиента с историей визитов и системой отзывов, административную панель, а также динамические блоки на главной странице.

---

## Основные блоки и функционал приложения

1. **Главная страница (Лендинг):**
   - **Hero-блок:** Приветственный баннер с быстрой кнопкой онлайн-записи.
   - **Услуги и цены:** Динамический каталог премиальных услуг барбершопа (стрижки, уход за бородой, бритье).
   - **Галерея работ:** Подборка лучших работ мастеров, подгружаемая из базы данных.
   - **Отзывы гостей:** Блок со статистикой (общий рейтинг ★ и количество отзывов) и лентой из 3 последних отзывов клиентов.

2. **Онлайн-запись:**
   - Выбор услуги, мастера и доступного времени (с шагом в 30 минут).
   - Защита от пересечения времени и бронирования на прошедшие даты.

3. **Личный кабинет клиента:**
   - Просмотр актуальных и прошедших записей со статусами (*Ожидает, Подтверждена, Завершена, Отменена*).
   - **Интерактивная система отзывов:** Возможность оставить оценку (от 1 до 5 звезд) и комментарий к визиту **только после завершения** сеанса администратором.

4. **Административная панель:**
   - Управление статусами клиентских записей, контроль базы услуг, мастеров и галереи.

---

## Технологический стек

* **Backend:** PHP 8.x (ООП, MVC-структура, PDO, кастомный роутинг)
* **Frontend:** HTML5, Bootstrap 5, CSS3, JavaScript
* **Database:** MySQL / MariaDB

## Установка и запуск (Open Server)

### 1. Клонирование / Перенос файлов
Поместите файлы проекта в директорию Open Server:
`C:\OSPanel\home\kingsman.local\`

### 2. Создание базы данных
1. Запустите локальный сервер (Open Server / MySQL).
2. Перейдите в **phpMyAdmin** (обычно по адресу `http://localhost/phpmyadmin` или через трей Open Server).
3. Создайте новую базу данных с именем: **`kingsman_db`** (кодировка: `utf8mb4_unicode_ci`).
4. При необходимости проверьте реквизиты подключения в `app/core/Database.php`:
   ```php
   $host = '127.0.0.1';
   $db   = 'kingsman_db';
   $user = 'root';
   $pass = '';
   ```

## Основной функционал

### Клиентская часть
* **Главная страница**: Промо-блок, краткая информация об услугах и мастерах.
* **Услуги (`/services`)**: Полный каталог услуг с ценами и длительностью.
* **Мастера (`/barbers`)**: Карточки барберов с аватарами, специализацией и стажем работы.
* **Онлайн-запись (`/appointment/create`)**: Запись к конкретному мастеру и на определенную услугу (работает через AJAX / POST).
* **Авторизация / Регистрация (`/login`, `/register`)**: Хеширование паролей (`password_hash`), валидация полей.
* **Личный кабинет (`/cabinet`)**: Просмотр истории собственных записей и их статусов.

### Панель администратора (`/admin`)
Доступна только пользователям с ролью `admin`:
* **Управление записями**: Изменение статусов (`pending`, `confirmed`, `completed`, `cancelled`) в режиме реального времени.
* **Управление услугами**: Добавление новых услуг и удаление существующих.
* **Управление мастерами**: Добавление барберов с указанием прямых ссылок на фото/аватары и удаление мастеров.

## Безопасность и архитектура

* **Защита от SQL-инъекций**: Все запросы к БД выполняются через подготовленные выражения PDO (`PDO::prepare`).
* **Единая точка входа**: Доступ к файлам вне папки `public` закрыт веб-сервером через `.htaccess`.
* **Автозагрузка классов (Autoload)**: Использование пространства имен (`namespace App\...`) по стандарту PSR-4.
